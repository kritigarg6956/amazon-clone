A static Amazon Clone website built using only HTML and CSS. This project recreates the basic layout and visual design of Amazon's homepage for frontend development practice.

🛠️ Technologies Used
HTML5
CSS3
✨ Features
Amazon-inspired navigation bar
Search bar UI
Product/category sections
Product cards and images
Shopping cart UI
Footer section
Responsive layout
🚀 How to Run
1.Clone the repository:
git clone YOUR_REPOSITORY_URL
2.Open the project folder.
3.Open index.html in any web browser.
